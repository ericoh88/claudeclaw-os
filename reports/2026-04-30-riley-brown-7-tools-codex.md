## Summary

- Riley Brown walks through 7 tools he uses daily alongside Codeex (and Claude Code) to 10x his AI agent workflow
- Core thesis: AI agents are only as good as the input and context you give them — the surrounding toolset matters as much as the agent itself
- Tools span voice input, clipboard management, screenshots, design, second brain, diagramming, and custom-built Electron apps
- Most tools are free or cheap; the "build your own" category is the most compelling long-term play
- Uploaded April 30, 2026 — all tools current as of this date

## Key Points

1. **Codeex context**: Riley's primary AI agent tool. Described as a hybrid of Claude Code + Claude co-work. Supports vibe coding, document creation (Excel, Word, PPT), multi-threaded sessions. Uses GPT 5.5 high/extra high. This sets the stage for why all 7 tools exist.

2. **Tool 1 — Whisper Flow** (whisperflow.ai): Voice-to-text that lives on the keyboard. Press Fn once = hold-to-record; double-tap = hands-free continuous recording. Text gets pasted wherever your cursor is. If you miss the cursor, the Whisper Flow history panel lets you copy recent transcriptions. Free plan is word-limited per week; Pro is $12/user/mo. Riley uses this to fire off agent prompts verbally while multitasking.

3. **Tool 2 — Raycast**: Clipboard manager (his stated #1 use). Cmd+M opens clipboard history, filterable by type (text, images, URLs). Saves 1 month of history. Also functions as a faster Spotlight replacement and inline calculator. Entirely free for his use case — he's never paid for it in 3 years. Workflow: copy research from multiple sources, then paste the whole stack into Codeex at once.

4. **Tool 3 — CleanShot X** (cleanshot.com): Screenshot/screen recording tool. Replaces Cmd+Shift+4. Cmd+Shift+5 for video recording with pause/resume. Captures float to side for immediate annotation (arrows, shapes, text). $30 one-time, local storage version (no cloud subscription needed). Workflow: annotate screenshots to give AI agents precise visual context; record demos, pause during loading, then drag directly into X/Twitter.

5. **Tool 4 — Paper** (paper.design): AI-powered Figma-like design tool with a Codeex MCP plugin. Say `/paper mcp` in Codeex and it designs directly on the open Paper canvas in real time. Supports inline image generation (OpenAI Image 2), image editing (glossier, frost effects), component references via shareable links. $16/mo annual, $20/mo monthly, free plan with tool-call cap.

6. **Tool 5 — Readwise / Readwise Reader**: Second brain. Auto-syncs X/Twitter bookmarks. Has a Codeex plugin and MCP — prompt it to "summarize my last 3 days on Readwise, group by topic, output as Word doc." $9.99/mo. Riley's use case: anything worth remembering gets bookmarked; agents can then mine the archive.

7. **Tool 6 — Excalidraw** (excalidraw.com): Hand-drawn style visual diagramming. AI agents (especially Codeex with his custom Excalidraw skill) are very good at generating Excalidraw diagrams. Example: used his YouTube Researcher skill to analyze Kane Callaway's channel, then auto-generated a 12-slide Excalidraw presentation. Free plan for basic use; $6/mo annual ($9.99/mo monthly) for saving multiple boards.

8. **Tool 7 — Build Your Own**: Use Codeex to build custom Electron desktop apps for niche personal needs in a single prompt. Example: "Leave a Comment" app — Cmd+Option+L opens it, lets him attach images/videos to Google Doc comments for his video editor. Built with Firebase storage, costs ~$3 in tokens. Template prompt: "Please create an Electron app that does [blank]. When you're done, please download it to my computer and I want to test it and use it." The philosophy: building tools for your own problems is how you accidentally build businesses.
